DevLadder: Programming Languages & Database Systems
Expanded reference catalog • Organized in tables by category
This catalog consolidates the languages, query languages, database systems, and database platforms listed in the conversation. It is a broad reference, not a literal inventory of every language or database ever created. Some entries are markup formats, frameworks, APIs, services, extensions, or historical technologies rather than standalone programming languages or database engines.

Notes and terminology
A programming language is not the same as a framework, markup format, query language, database engine, or hosted service.
Some products appear in more than one category because they support multiple data models or workloads.
Names and product status can change. Some entries are historical, discontinued, experimental, or legacy technologies.
This document consolidates the expanded lists discussed in the conversation; it is not a verified exhaustive census of every language or database ever created.
